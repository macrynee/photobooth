# 📸 SnapBox Studio — Interactive React Photobooth & Admin System

A complete photobooth web application built with **React**, **TypeScript**, **Tailwind CSS**, and a **Node.js/Express** backend with **PostgreSQL (psql)** support.

---

## 🔒 Access Code Protection & Admin Workflow

1. **Photobooth Access Dialog**:
   - Before users can access the booth, a full-screen **Access Code Gate** dialog appears.
   - Users must enter a valid access code (e.g., `SNAP-2026`) generated by the admin to unlock the studio.
   - The backend validates the code, checks expiration, ensures uses have not exceeded `max_uses`, and tracks redemptions.

2. **Admin Authentication**:
   - **Login Page**: Sign in with admin username/email and password.
   - **Register Page**: Create new administrator accounts (passwords securely hashed with `bcrypt`).
   - **Default Admin Credentials**:
     - **Username**: `mac`
     - **Password**: `macqwerty`

3. **Admin Dashboard**:
   - **Metrics Overview**: Total codes generated, active codes, total redemptions, and total photo strips.
   - **Generate Access Code**:
     - Custom code string or auto-generate (e.g. `SNAP-8A9X`)
     - Customer / event notes (e.g., "Sarah's Wedding - Table 4")
     - Usage limit (1 session, 2, 5, 10, or unlimited 999)
     - Single or batch creation (1 to 10 codes in 1 click)
   - **Code Management**: Toggle active/inactive, copy code, search/filter, and delete.
   - **Recent Photo Strips Gallery**: Live gallery of captured strips with associated access codes.
   - **Launch Photobooth**: One-click shortcut to launch the photobooth directly.

## 🐘 PostgreSQL (psql) Database Schema

The complete PostgreSQL database schema file is located at:
`database/schema.sql`

### How to apply to your PostgreSQL database:

```bash
psql -U postgres -d your_database_name -f database/schema.sql
```

### Tables Created:
1. `admins`: Admin accounts with bcrypt password hashes and roles.
2. `access_codes`: Access codes with max uses, current redemptions, activation flag, notes, and expiration.
3. `photo_sessions`: Photo strips saved with layout, filters, base64 image data, and access code references.
4. Automatic `updated_at` triggers and performance indexes.

### Database Configuration:
Set your connection string in `.env`:
```env
PORT=5000
JWT_SECRET=snapbox_super_secret_jwt_key_2026
DATABASE_URL=postgresql://postgres:postgres@localhost:5432/photobooth
```
> **Zero-Friction Fallback:** If a PostgreSQL server is not yet running, the backend seamlessly falls back to a persistent JSON store (`database/local_db.json`), so all authentication, code generation, and booth verification work immediately out of the box!

## 🚀 Running the App

### Start Backend Server:
```bash
npx tsx server/index.ts
```
*(Runs on `http://localhost:5000`)*

### Start Frontend Dev Server:
```bash
npm run dev
```
*(Runs on `http://localhost:5173` with proxy to backend)*

- **Photobooth URL:** `http://localhost:5173`
- **Mobile QR Code Scan URL:** `http://192.168.8.139:5173`
